# 🌍 TerraAI — AI Assistant for SDG 13

TerraAI is a simple AI-powered chatbot that promotes environmental awareness and sustainable living.
The chatbot helps users learn how to reduce their carbon footprint and supports **SDG 13: Climate Action**.

---

## 📌 Features

* AI-powered chatbot using Google Gemini
* Provides eco-friendly suggestions
* Answers sustainability-related questions
* Simple and interactive Streamlit interface
* Supports awareness for climate action

---

## 🛠️ Technologies Used

* Python
* Streamlit
* Groq API
* python-dotenv

---

## 🎯 SDG Goal

This project supports:

### SDG 13 — Climate Action

The chatbot spreads awareness about:

* Reducing carbon footprint
* Sustainable habits
* Energy conservation
* Environmental protection

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone <your_repository_link>
cd TerraAI
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Add Gemini API Key

Create a `.env` file and add:

```env
GROQ_API_KEY=your_api_key_here
```

---

## ▶️ Run the Application

```bash
streamlit run app.py
```
